AESYN Performance — v0.60.8-r1 — Demo Identity Exact Match Gate Fix

Hotfix da mesma versão funcional v0.60.8.

Causa:
- a implementação JavaScript usa corretamente:
  return /^(Dr\.?\s*Testinho|Doutor\s+Testinho)$/i.test
- o TESTAR.ps1 procurava barras duplicadas porque foi escrito com `\\`
  dentro de string PowerShell;
- PowerShell não usa backslash como caractere de escape, então o gate
  buscava uma assinatura inexistente e gerava falso negativo.

Correção:
- usa string PowerShell literal com a assinatura real do JavaScript;
- mantém o match exato para proteger nomes reais;
- não altera o Chat, sidebar, busca, badge ou identidade funcional;
- exatamente um BOM UTF-8.

Arquivos:
- PREPARAR.ps1
- VERSION.txt
- ARQUIVOS-ALTERADOS.txt

O PREPARAR altera TESTAR.ps1 e se substitui pelo PREPARAR final idempotente.
Sem commit individual de -r1.
