AESYN Performance — v0.60.6-r3 — Series Blocks Backend Compile Fix

Hotfix da mesma versão funcional v0.60.6.

Causa:
- ExtrairBlocosSeries retornava:
  List<TemplateBlocoSerie> ?? TemplateBlocoSerie[]
- o operador ?? nao aceita List<T> de um lado e T[] do outro;
- a API nao compilava/subia e o AESYN AUTO expirava aguardando
  http://127.0.0.1:5180.

Correção:
- troca somente o fallback do deserialize:
  ?? Array.Empty<TemplateBlocoSerie>()
  por
  ?? new List<TemplateBlocoSerie>()
- adiciona dotnet build -c Release no PREPARAR do hotfix;
- se houver outra falha de compilacao, ela aparece antes do RODAR;
- PREPARAR final mantém Regression Memory textual contra o bug;
- nenhuma mudança de escopo funcional;
- exatamente um BOM UTF-8.

- PREPARAR.ps1
